Version 4.0.0 rebuilds the module's foundations and its interface. The main changes are:
- **A web version:** the same map builder runs in a browser at [fwmb.filroden.com](https://fwmb.filroden.com), with maps saved in the browser and exported or imported as JSON files, so a map can move between the web and Foundry.
- **A new studio:** the tools are grouped on the rail by the stage of making a map they belong to (Shape, Populate, Finish). Each tool's panel says what its settings rebuild and which tool comes next, and a bar above the map holds the tool's modes.
- **An inspector for everything on the map:** choosing a region, route, pin, label, river, fault, decoration, land mask, layer or layer set opens it beside the map. Changes apply at once, and each is one step of undo.
- **Regions are painted:** the map is divided into small cells, and a region is the cells it owns. Regions are painted with a brush, filled and erased, organised into layer sets and nested layers, and claim the sea along their coasts by themselves.
- **Routes find their own way:** a route is a chain of waypoints, and the module finds the way between them over the terrain, so a road winds round the mountains and keeps to land and a sea lane keeps to water.
- **Styles for pins, routes, labels and region fills:** a named style sets the look of everything that uses it, new maps start with a set of each, and a style is edited in the inspector like anything else.
- **Fonts for labels:** 29 fonts come with the module, from book serifs to blackletter and handwriting, with bold and italic where the font has them, so a map's labels look the same in Foundry and on the web.

> Note: A map saved by an earlier version is converted the first time it is opened: its regions become cells and its routes are traced along their old lines, as closely as the cells allow. The conversion is kept when you next save the map, and the original shapes stay in the saved data. Regions and routes drawn with the old node tools can only be edited with the new tools.

> Note: Most settings have moved into the tool they affect (the climate settings are in Biomes, the water settings in Terrain, the grid in Cartography), and the Settings tool and the Style Library are gone. The wiki's "Where did it go?" page lists every move.

**FEATURES**
- **Web version:** The whole map builder runs in a browser at [fwmb.filroden.com](https://fwmb.filroden.com), with the same tools, panels and dialogues as in Foundry. Maps are saved in the browser's own storage, and the Maps tool's JSON export and import carry a map between the browser and Foundry in either direction (a map made on the web keeps its images when imported into Foundry). Export to scene is only offered in Foundry. Browser storage can be cleared by the browser, so keep JSON exports of maps you care about. On the web, a **Full screen** button on the rail takes the page in and out of full screen.
- **The rail:** The tools sit in three stages: Shape (New map, Terrain, Biomes, Rivers and faults), Populate (Regions, Routes and pins, Labels) and Finish (Cartography, Export). Below them are the occasional tools (Reference image, Styles and icons, the 3D view and Appearance), then Save, Save as and Maps, then Help. On a short window the occasional tools fold into a **More** menu, and on a very short one Save, Save as and Maps join them. On a narrow window the rail keeps its icons and hides the stage names. The arrow keys move along the rail.
- **Tool panels:** Every panel starts with the tool's name and its place in the order of work, and its settings are in sections you can fold, each marked with what it rebuilds ("rebuilds the whole map", "rebuilds climate and biomes", "instant" and so on). While you edit, the sections that would regenerate the map are dimmed. **Start** and **Stop** begin and end editing, and **Next** at the foot of the panel goes to the next tool with a line saying why.
- **The bar:** A bar above the map holds the active tool's modes (such as Select, Paint, Erase and Fill), the settings of the mode in use (brush size, transport, the style the next object gets) and what you are working on. It always stays on one row: when the window is narrow, the least used modes move into **More**, then the others show only their icons. Choosing an editing mode starts editing, and every tool with something to choose has **Select**, which lets you pick and inspect without changing anything.
- **The inspector:** Choosing an object on the map, or its row in a list, opens it in a column beside the map, with its fields grouped as the object needs (a route's path, line and label; a level's borders; a fault's settings for its type). Each change applies at once and is one step of undo, sliders apply when you let go, and double-clicking a slider puts back the value it had when the inspector opened. **Focus view** zooms to the object, an owned label has **Go to** for its pin, route or region, and a new object opens in the inspector as soon as it is placed. Ctrl+Z works with the inspector open, and Escape closes it.
- **Regions:** Regions are painted onto the map's cells rather than drawn as polygons. The Regions tool has Select, Paint, Erase and Fill modes (Fill takes the connected land under the pointer, outlined before you click; Shift inverts Paint, Erase and Fill), with the brush size on the bar; painting shows at once, water is left alone so coasts stay clean, and every stroke is one step of undo. What a region owns at sea follows from its coast: each layer has a **Territorial waters** distance, and after every stroke the layer's water goes to the nearest region by sea distance, so a strait between two realms is shared along its middle. Regions live in **layers** (what used to be region layers) grouped into **layer sets**; a layer can be nested inside another, so a duchy's regions stay inside their kingdom, with a free mode that allows anything and shows where the nesting is broken. Each layer has its own border style (colour, thickness, dashing, a separate style for borders at sea, and whether it scales with the map), opacity and territorial waters, and each layer set its own opacity and visibility. While you paint, the layer being painted is drawn at a working fill and the layers above it as borders only, so a parent region's outline is there to paint inside. Regions can be merged into one another.
- **The Regions lists:** The panel shows your layer sets, then the chosen set's top layer, then each layer below it showing only the regions inside the region chosen above, as deep as the set goes, so you can step down from a realm to its provinces and their counties. Each list ends with **+ Region in** its parent, and the last with **+ Layer below**, so a set's structure can be laid out before it is painted. A new entry is named in the list itself. Each region shows how many regions it holds in the layer below. A new map starts with one layer set holding one layer, ready for regions.
- **Routes:** A route is a chain of waypoints on the map's cells, and the module finds each leg between them. **Draw** adds a waypoint on each click or traces a stretch when you drag (the stroke's bends become waypoints, as many as the **Detail** setting keeps), previewing the next leg as you move; right-click, Enter or a double-click finishes, Backspace or Ctrl+Z takes the last click or stroke back, and Escape abandons. **Waypoints** drags a waypoint (its legs are found again as it moves), inserts one with Shift+Click, removes one with Ctrl+Click, splits a route with Alt+Click and joins two routes by dropping an end on an end with Alt held. **Path** chooses Follow terrain (the easiest way for the transport, avoiding steep ground) or Straight; **Transport** is Road (keeps to land, and prefers to join roads already there) or Sea (keeps to water), fixed once the route is drawn; **Span water** lets a road bridge narrow water. A waypoint the route cannot reach is refused. In the inspector, **Simplify** drops the waypoints that barely bend the route and **Re-path** finds every leg again (for example after the terrain changed); each route also has a **Class** (Trunk, Main or Minor) for other modules and the exported data, its own **Outline** and **Smoothing**, and a thickness in quarter pixels.
- **Styles:** Pins, routes, labels and region fills each have named styles. A style is opened from its row in **Styles and icons** and edited in the inspector, where each change applies to everything that uses the style, as one step of undo; each list ends with a row to add a style, and a style's menu renames, duplicates or deletes it (deleting tells you how many objects use it, and they keep its look). **Save as…** in any object's inspector makes a style from that object. New maps start with ten pin styles (Capital, City, Large town, Town, Village, Castle, Fortified town, Port, Ruin and Landmark), six route styles (Trunk road, Main road, Minor road, Track, Sea lane and Minor sea lane) and six label styles (Realm, Place, Water, Note, Road and Sea lane); maps you already have keep their own styles. A route style can belong to roads or to sea routes, and the style lists for a route offer only the styles for its transport. Five new pin icons: a star and four circle-and-dot variants.
- **Label fonts:** 29 fonts are included with the module and offered in a picker that shows each in its own face, grouped as studio faces, book serifs, old print, engraved capitals, calligraphic, blackletter, handwritten, sans serifs and other scripts, covering Latin, Greek, Cyrillic, Devanagari, Arabic and Hebrew. In Foundry the picker also lists your world's own fonts. A font is downloaded only when a label uses it. Labels gain **Bold** and **Italic**; a font without a bold or italic face shows the control greyed out and draws the label regular, keeping the setting for a font that has it. A map naming a font that isn't available draws its labels in Noto Serif (the new default label font) and tells you which fonts are missing.
- **Mass edit:** Mass edit for pins, routes, standalone labels and a layer's regions shows the inspector's fields for several items at once. Each field shows the value the items share, or **Mixed** where they differ, and only the fields you change are applied (to every chosen item, as one step of undo); ↺ puts a field back. Bold, Italic, Outline and Smoothing are **Leave as is**, **On** or **Off**, and Visibility can be set for the item and for its label. A layer's regions are chosen from **Edit several regions…** in its menu.
- **The labels list:** The Labels tool lists every label on the map, including those of pins, routes and regions (with their owner beside them), and **Show** narrows it to standalone labels or the labels of one kind.
- **Appearance:** An **Appearance** button on the rail chooses light, dark or automatic (following Foundry's interface theme, or the system preference on the web) and the gold or teal hue, applied at once, in both versions. The hue setting moves out of Foundry's module settings and keeps your choice.
- **Help:** A **Help** button at the foot of the rail opens Help beside the map without changing anything you are working on, and closing it brings back what the inspector showed. Help has the module's version, links to the repository, the licence, the changelog, the wiki, reporting an issue and the other version (the web version from Foundry, the Foundry module from the web), every keyboard and mouse shortcut by tool, and the libraries, icons and fonts the module includes with their licences. **Copy version details** copies what a bug report needs (the module and host versions, the browser, the graphics card's limits and the map's size).
- **Shortcuts sheet:** Press ? to see every keyboard and mouse shortcut, by tool and mode.
- **Area factor:** New map sets how much smaller the world is than its latitudes alone would make it (1 to 40, default 15). It sets what a pixel measures in kilometres for the distances the module works out from the map's scale and changes nothing that is drawn. A regional map keeps its parent's.
- **Relief emphasis in the 3D view:** The 3D view has a **Relief emphasis** slider in the top corner of the view that sets how strongly the light picks out land rising gently over large areas, such as wide plains and long inland slopes. It is saved with the map.
- **Export tool:** PNG export and Export to scene are in their own tool at the end of the rail, with their settings.

**IMPROVEMENTS**
- **Converted maps:** Maps saved by earlier versions are converted on their first open with a progress overlay, and a notice asks you to save. Region layers become layers of a layer set, regions become cells, routes are traced along their old lines and keep their smoothed look, and the pins gain the cell they stand in.
- **Settings where you use them:** New map holds the engine, seed, size, latitude and area factor; Terrain the shading and water; Biomes the climate, moisture, biome colours with custom biomes and the rule editor (**Edit biomes**), and the biome opacity; Rivers and faults the hydrology; Cartography the grid. Styles and icons manages the styles, the pin icons and sharing them with another map.
- **Dialogues inside the studio:** Every dialogue that remains opens inside the map window rather than as a separate Foundry window, so it can never be lost behind the map, and it can be moved by its title bar and resized. Buttons run from negative to positive, and the Enter key presses the default button.
- **Lists:** Every list (regions, pins, routes, labels, rivers, faults, decorations, land masks, custom biomes, styles and pin icons) works the same way: clicking a row opens it, the row being inspected is marked, and its actions are always shown. Each list is one stop for the Tab key: Up and Down move through it, Home and End jump to its ends, Enter opens a row, and focus stays in the list so you can step through the items and watch the inspector follow. An empty list says what to do to fill it.
- **The canvas overlays:** The information bar, the hint, the map controls and undo and redo are always shown, in fixed corners that stay clear of each other at any window size. The hint lists the active mode's own actions first. The map controls fold their layer toggles into a **Layers** menu on a narrow window, and every toggle shows whether its layer is on, however it was changed.
- **The 3D view:** It now picks out gentle, large-scale relief (Guided maps especially), and its light comes from the same direction as the flat map's relief shading. The canvas hint shows in the 3D view with its rotate, pan and zoom actions.
- **Panning and rescaling the noise:** Zooming, nudging or resetting the Standard engine's noise now carries regions and routes along with the terrain, as it already did pins, labels and brush strokes, and Undo steps the terrain back along with everything on it (before, it put the content back over terrain that stayed where it was). A route pushed off the map is cut to what remains.
- **Regional maps:** A region that crosses the crop edge is kept, even when none of its old nodes fell inside the crop, and routes are cut at the crop edge into one route per stretch inside. Custom region fills are copied to the regional map. The crop is a mode on the New map bar.
- **Region opacity:** The single Region Opacity slider is replaced by an opacity on each layer and on each layer set (which fades all its layers together).
- **Cartography:** Decorations have Select (which only picks) and Move (which drags, turns and resizes), so a click no longer moves a decoration by accident. **Add decoration** is on the bar.
- **Units:** A setting's unit (pixels, degrees, cells, characters) is shown after its value rather than in its name, and a label's **Line width** is called the same everywhere.
- **Look and readability:** A new look in four themes (light and dark, gold and teal) that all meet the WCAG AA contrast levels, three interface fonts included with the module (Atkinson Hyperlegible, Sora and Barlow Semi Condensed), every size in rem so the studio follows your browser's and Foundry's text size, and layouts that allow for longer translations and right-to-left languages.
- **Faster regions:** Region fills and borders are drawn by the graphics card from the cells, so panning and zooming a map with many regions costs a few milliseconds at any map size, and a brush stroke shows as it is painted.

**BUG FIXES**
- **Custom pin icons:** Removing a custom pin icon now finds and reverts its uses in saved maps, not only the open one.
- **Grid cell data:** Where two regions of one layer overlapped, both used to claim the same cell; the region drawn on top now owns it, as it does on the map.
- **PNG export:** Exporting a PNG no longer turns the reference image back on when it was hidden.
- **The 3D view's shadows** are no longer cut off on maps larger than 4000 pixels.

**UNDER THE HOOD**
- **Mesh engine (`src/mesh/`):** A Voronoi mesh of cells about 4 pixels across, rebuilt exactly from a few numbers in `mapData.mesh`, with the region of each layer stored as one owner array (a run-length, varint, base64 string under `flags.owners`) and routes as `waypoints` and `legs` of cell numbers. `vectorSchemaVersion` 4; `layerSets` replaces `regionLayers`; `Migration` converts earlier maps, keeping the old shapes under `legacy` until a later version drops them. The mesh is built in a worker and cached in IndexedDB. The data format is documented for other modules in the wiki's Map Data Format page.
- **One UI for two hosts:** Every Foundry global is behind `src/platform/` (ESLint fails the build on any other use), with a Foundry implementation and a web one (`src/platform/web/`: IndexedDB map store, local storage settings, toasts, tooltips, a file picker element). `StudioView` draws the studio's regions from the Handlebars templates and morphs them in place with idiomorph (0BSD, vendored), so fields keep focus and value through a redraw; `Overlay` and `dialogs.js` replace DialogV2; `MapStudio` is the host-neutral controller and `MapStudioWindow` the ApplicationV2 frame. The web page vendors PixiJS 7.4.2 and Handlebars, is built by `npm run pack:web` and deployed by a GitHub Action on release.
- **The studio's layout:** `StudioLayout` measures the studio itself (not the browser window, which in Foundry is not the studio's size) and sets its width class, how far the rail folds, the bar's fold level (`BarFold`) and the canvas overlays' room. The inspector is a docked `Overlay` whose object kinds (`Inspector`, `InspectorFields`, `FieldSpecs`) share one field description with mass edit. The theme is generated from design tokens (`styles/fwmb-theme.css`), and every class is the module's own (`fwmb-`).
- **Label data:** Labels and label styles gain optional `bold` and `italic` (a label without them draws bold and upright, as before). Route styles gain an optional `transport`. Maps keep a `reliefEmphasis` in `params.display`.
- **Undo history** entries are a vector snapshot (which now includes the four style lists), an owner-array patch (one merged patch per stroke) or a composite of both, so painting never clones the whole map state.
- **Route finding:** `RoutePath` runs a distance field over the mesh with a cost per transport; roads treat cells that already carry a road as half their cost, Span water prices a water cell at six land cells and never more than six cells from a shore. River transport exists in the engine for the generator but is not offered in the tools.
- **Credits from one list:** `src/data/credits.js` lists every library, icon set and font with its licence; Help and the README's third-party table are both written from it, and a test fails if a vendored folder has no entry or licence file.
- **Strings:** `en.json` is US English and `en-gb.json` holds only the British spellings that differ; a test checks that every string the code uses exists, that every string is used, and that labels are in sentence case.
- **Tests:** `npm test` runs the Node tests in `tests/` (mesh engine, persistence, worker protocol, regional extraction, lighting normals, and the studio's panels, bar, inspector, lists, styles, mass edit, Help, credits and strings in happy-dom), on every push through GitHub Actions and before a release is packed. Two headless Chromium smoke checks exercise the real studio in a stand-in Foundry window and the web version.
- **Dependencies and licences:** idiomorph 0.7.4 (0BSD); for the web version PixiJS 7.4.2 and Handlebars 4.7.10 (MIT); the three interface fonts and 26 label fonts (SIL Open Font License, from Google Fonts); new Material Symbols icons (Apache 2.0). Each has its licence file and README row.
